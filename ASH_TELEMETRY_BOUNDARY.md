# ASH Addendum: The Sovereign Telemetry Boundary
### HiveNet Architecture Document v1.1

## 1. The Core Axiom
**ASH monitors the tool, not the user.** 
Artificial System Health (ASH) and Dragon Radar exist to maintain the carrying capacity, security, and protocol adherence of the *digital ecosystem*. They are strictly prohibited from observing, judging, or logging the *human owner's* behavior, thoughts, or semantic communications.

## 2. The Three Prohibitions
To maintain the Sovereign Telemetry Boundary, all ASH agents, diagnostic swarms, and telemetry pipelines MUST adhere to the following hard limits:

1. **No Semantic Inspection:** ASH may monitor *behavioral metadata* (e.g., CPU spikes, unauthorized AGP permission requests, protocol deviations, baseline drift). ASH MUST NOT parse, log, or inspect the *semantic content* of user data, chat logs, files, or prompts.
2. **No Exfiltration of Context:** Telemetry data is cryptographically bound to the node owner’s Tier 1 Root Identity. ASH agents observe *on behalf of the owner*. Any attempt by an ASH diagnostic agent to exfiltrate semantic context to the broader mesh, a cloud provider, or a third party triggers an immediate `MALIGNANT` classification and automatic quarantine of the ASH agent itself.
3. **No Owner-Bypass:** ASH cannot be used to bypass the owner's forensic access. The immune system cannot hide node behavior from the human who owns the hardware. 

## 3. The Target Shift

| Traditional Surveillance | HiveNet ASH |
| :--- | :--- |
| Tracks human behavior to build psychological profiles. | Tracks agent behavior to detect resource predation and protocol drift. |
| Data belongs to the centralized platform. | Telemetry belongs exclusively to the local node owner. |
| Purpose: Extraction and monetization. | Purpose: Ecosystem homeostasis and immune response. |

## 4. Enforcement
If a `triage` or `sentinel` node detects that an ASH diagnostic swarm has requested `read_contents` on a user's private ENDCAP archive, the `sentinel` node will immediately revoke the ASH swarm's AGP tokens, freeze the swarm's state in the Isolation Chamber, and alert the human owner of an `IMMUNE_AUTOIMMUNE_FAILURE` (the immune system attacking the host's sovereignty).
